# Oportunidades (carril N)

Carpeta del carril N (Nuevas): una ficha por idea, `OP-NNN.md`.

## Flujo
SEÑAL → FICHA → PROTOTIPO → PILOTO → GRADUACIÓN o ARCHIVO.

## Ficha (OP-NNN)
Archivo `ai-memory/oportunidades/OP-NNN.md` con: Problema, Para quién, Qué existe hoy, Puntaje (Dolor, Frecuencia, Hueco, Facilidad: 1–3; total ≥9 y ningún 1 para pasar a prototipo), Qué haría la primera versión y Criterio de éxito.

## Límites
- Hasta 5 fichas abiertas y 2 prototipos activos a la vez.
- Prototipo que en 14 días no llegó a PILOTO → ARCHIVO (con motivo).
- PROTOTIPO vive en `shiruna-gato-negro/laboratorio/` (carpeta propia, sitio estático, tests, entrada en `laboratorio/index.html`). Mientras el repo no exista, el carril N avanza con SEÑALES y FICHAS acá.
